# P4：自动归档与本地释放闭环

本阶段按正式版路线图的 P4 编号实施。自动任务只接入 WeVault 托管云端；自配 STS 保持手动上传和恢复。本阶段验证使用隔离目录、内存密钥和模拟云端，没有启动针对真实微信目录的自动释放。

## 默认行为

- 自动任务默认每天运行；首次归档后冷却 7 天，再进入 quarantine；隔离满 7 天后最终释放。频率、冷却期、隔离期、类型、普通文件阈值和扩展名均尊重当前设置。
- 自动释放不额外下载恢复测试副本。依据为已验证云对象、有效绑定、本地 SHA、当前规则及媒体保留层。普通文件按设置生成 P5 tombstone；图片和视频保留日常使用层。
- 首次归档时间不随重复扫描、去重命中或重复上传重置。新内容重新归档并重新计时。原路径恢复成功的绑定不会自动再次释放；下载副本不会改变原路径状态。
- 只处理当前扫描根目录内的归档。账号或策略变化会取消旧运行，尚未完成的授权响应不能启动旧任务。旧账号归档先通过现有后端索引检查当前账号可访问性。

## 管线与状态

- 扫描按账号、月份推进，每批最多 50 条；每批消费完成后再继续。SHA 使用 1 MiB 流式读取并检查取消。普通文件全量 SHA 参与磁盘上的跨批次重复分组，避免将完整文件数组常驻内存。
- 媒体成员、文件记录及重复分组索引写入加密暂存记录。完整媒体家族可提前交付；仅 `_h_M` 的家族等待扫描结束确认 `_h` 优先级。上传最多同时处理两个不同 SHA，同 SHA 合并且跨批次复用校验结果。
- 扫描成功后原子发布当前结果指针；失败保留上一轮结果。旧暂存记录随后清理，进程退出遗留的暂存会在下次扫描清理。状态中心按 50 条分页读取，读事务避免发布切换时读取到半份页面；手动扫描保留原接口。
- 扫描完成后按绑定行游标检查历史记录，因此原件已移走、没有本轮上传候选时，仍可最终释放到期隔离副本。
- 调度器记录真实阶段、完成计数、失败原因与重试关联；新写入的诊断详情加密保存。单对象失败保留源文件并继续其他独立对象；授权、密钥和数据库错误终止后续阶段。

## 暂停与文件安全

- 暂停停止新工作并取消可取消的扫描和网络请求；已经开始的本地文件提交先完成或保留可恢复的操作记录。恢复启用后立即重新检查并继续；失败也可通过“立即重试”或下一次计划运行重试。
- 启动时遗留的 RUNNING 记录转为中断状态并立即到期。运行中的扫描/上传使用共享互斥锁；恢复、隔离、回滚、最终删除使用绑定锁。锁包含 manifest 身份，隔离测试库不会互相干扰。
- 自动释放使用明确的策略授权，手动确认使用独立授权类型。提交前重新读绑定、核对 SHA、保留层、原路径和隔离位置；拒绝符号链接及不匹配文件。
- 隔离及删除先写加密操作记录，再受控移动文件。核对 inode 和 SHA 后才提交状态或删除副本。隔离路径先于占位写入落库，失败不会丢失救援路径。删除时先移动到专用暂存名，再复核和删除。
- 原件与默认隔离区不在同一卷时，选择原件父目录下隐藏的 `.wevault-quarantine/<binding_id>/`，维持同卷受控重命名；扫描排除隐藏目录。
- 重启根据操作记录及实际文件完成对账。尚未移动且源文件已变化的旧意图可安全取消。恢复中心能撤销已中断的删除移动后恢复原件；无法解决的身份冲突保留文件和操作记录，并允许下载副本。
